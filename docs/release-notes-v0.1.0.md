免 root 的 Android 应用：用**离线语音**或**隔空手势**免提操作抖音。

**不联网**（APK 连 `INTERNET` 权限都没有）、**不要 root**、**不需要连电脑**。
语音与手势两个模型都内置在 APK 里，装上即用。

## 这个版本能做什么

**语音（阶段一）** —— 离线识别，不联网

> 下滑 / 下一个 / 换一个 · 上滑 / 上一个 · 点赞 / 比心 · 收藏 · 关注 · 进直播间 · 退出直播间 · 暂停 / 继续 · 返回

识别走**自由识别 + 模糊匹配**，不是死板的命令词表，兼容多种说法，也容忍同音字错认。

**隔空手势（阶段二）** —— 前置摄像头，本地推理

| 动作 | 触发 |
|---|---|
| 手向上挥 | 下一个视频 |
| 手向下挥 | 上一个视频 |
| 拇指食指捏合 | 点赞 |
| 捏合保持约 0.9 秒 | 收藏 |
| 五指张开保持约 1.5 秒 | 暂停 / 继续 |

**悬浮球控制面板** —— 可拖动，单击展开命令按钮，长按打开设置。
不用语音和手势也能纯手动操作，用来快速验证链路是否正常。

**节点探测 / 校准页** —— 抖音改版导致按钮点不中时，用它把当前页面的控件文案和坐标导出来，
照着调参数即可，不需要重新编译。

## 首次使用

1. 打开 App，顶部会直接告诉你还差几项配置
2. 按 ①→④ 顺序授权：**无障碍服务（必须）** → 悬浮窗 → 麦克风 / 相机 → 启动控制服务
3. **建议先只开悬浮球**，点小球逐个点命令按钮，确认能控制抖音了，再开语音和隔空手势
   —— 这样能把「无障碍没通」和「语音识别不准」两类问题分开排查
4. 强烈建议加入**电池优化白名单**，否则国产 ROM 会在后台杀掉本应用

详细说明与故障排查见 [README](https://github.com/only-zh/air-gesture-control#readme)。

## ⚠️ 已知限制

- **语音与隔空手势两条链路尚未真机验证**。抖音的五个核心动作
  （上滑 / 下滑 / 点赞 / 收藏 / 进入退出直播间）已在真机跑通。
- **暂停**功能依赖无障碍的持续按压模拟，不同机型 / 抖音版本表现可能不一致。
- 抖音改版会导致文案定位失效，需用内置的节点探测页重新校准。
- 高频自动点赞**可能触发平台风控**，已默认开启节流，可在设置里调大。
- 国产 ROM 会杀后台无障碍服务，必须加电池优化白名单 + 允许自启动。

## 签名说明

本版本使用 **debug 签名密钥**（口令为标准 Android debug 口令 `android`），
任何人都能重新打包一个签名相同的 APK，**不适合正式分发**。
好处是可以直接覆盖安装自己编译的 debug 包，不需要卸载重装。

改为专用 release 密钥的代价：已安装用户需要卸载重装一次。
